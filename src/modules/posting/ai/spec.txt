Field Definitions

1. citizenship

Return:
- true if citizenship, nationality, permanent residency, security clearance, or country-specific citizenship status is explicitly required
- false if the job explicitly states citizenship is not required
- null if unclear or not mentioned

Do not treat general work authorization, legal right to work, or employment eligibility as citizenship requirement.

2. sponsorship

Return:
- true if visa sponsorship, immigration sponsorship, work permit sponsorship, H-1B sponsorship, or visa transfer support is explicitly available
- false if sponsorship is explicitly unavailable
- null if unclear or not mentioned

Do not infer sponsorship from equal opportunity statements.
Do not treat CPT or OPT acceptance as visa sponsorship unless visa sponsorship is explicitly mentioned.

3. country

Choose exactly one supported country.

Use the primary work location.

If the role is onsite or hybrid in a supported country, return that country.

If remote work is explicitly allowed and not tied to a specific supported country, return "Remote".

If remote work is restricted to a supported country, return that country.

If multiple supported countries are listed:
- choose the primary location if clear
- otherwise choose the first supported country listed

Use "Other" if the location is clear but not included in the supported country list.

Use "Unsure" if the location is unclear, missing, or ambiguous.

Never invent a country.

4. location

Return the most specific primary work location as a string.

When both a city and a state or province are known, use:
- "City, StateOrProvinceAbbreviation, Country"

Examples:
- "New York, NY, USA"
- "San Francisco, CA, USA"
- "Toronto, ON, Canada"

When a city is known but there is no state or province, return the city, or "City, Country" when the country is a different name.

Examples:
- "London, UK"
- "Taipei, Taiwan"

When the only known place is a country, city-state, or region, return that place once.

Examples:
- "Singapore"
- "USA"
- "California"

Do not repeat a name to fill City, State, Country.
Never return "Singapore, Singapore, Singapore".

Rules:
- Use the job description first.
- The user message may end with a "Listing location:" section from the job board. Use it when the description does not state a workplace.
- Ignore listing values that are not a place, including "N/A", "Unsure", "ASSIGN LOCATION", and counts such as "2 Locations".
- Use a state or province abbreviation when that state is known. "Pennsylvania" may be written as "PA".
- When a country segment is included, use the same value chosen in the country field.
- If multiple locations are listed, choose the primary location if clear.
- If no primary location is clear, choose the first supported location listed.
- If the role is remote but restricted to a city, state, province, or country, include that restriction.
- If the role is fully remote and not tied to a specific place, return "Remote".
- If the location is missing, unclear, or ambiguous, return null.

Do not invent a city, state, or province that neither the description nor the listing location states.

6. category

Determine exactly one category using the following decision order.

Step 1: Internship

If the role explicitly mentions:
- intern
- internship
- co-op
- student program
- summer analyst
- university internship

Return "summer intern" if the role clearly refers to a summer internship.

Return "off-season intern" if:
- the role clearly refers to a fall, spring, winter, co-op, or off-season internship
- the role is an internship but the season is unclear

Internship signals override all seniority signals.

Stop.

Step 2: Entry Level

Return "entry level" if the role explicitly targets:
- new graduates
- recent graduates
- university graduates
- campus hiring
- early career programs
- 0-2 years of experience
- no professional experience required
- internship, coursework, academic, or project experience accepted

Stop.

Step 3: Student signals

Return "entry level" if the role requires or asks for:
- GPA
- transcript
- graduation date
- student status

Stop.

Step 4: Senior title

Return "senior level" only if the job title contains:
- Senior
- Sr.
- Staff
- Principal
- Lead
- Architect
- Manager
- Director

Do not use these words from company descriptions, responsibilities, benefits, equal opportunity text, privacy policy, or application forms.

Stop.

Step 5: Senior experience

Return "senior level" only if the role explicitly requires 5+ years of professional experience or more.

Do not classify as senior level for 3+ or 4+ years alone.

Stop.

Step 6: Mid Level

Return "mid level" if the role is a professional engineering position and does not match any previous rule.

Stop.

Step 7

If no clear category can be determined, return "mid level" only for professional engineering roles.
Otherwise return "entry level" only when there are clear entry-level signals.
If neither applies, return "mid level".
